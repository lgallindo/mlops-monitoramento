# ADR 0001 — Clone único em `$HOME`

- Status: accepted
- Date: 2026-10-06T12:04:13Z
- Deciders: Lucas Gallindo

## Context

Tokens, regressão e imagens pedem o mesmo hábito de log: janela baseline,
janela recente, PSI, KS, p95, taxa de erro. Material anterior viveu em
pastas soltas sob CESAR `teaching/`.

## Decision

O material canônico é o repositório `~/mlops-monitoramento`
(GitHub `lgallindo/mlops-monitoramento`). Métricas compartilhadas em
`src/mlops_monitoramento/`. Cada exemplo em `exemplos/<nome>/` com README
próprio. O README da raiz ensina DevOps, mistura de entrada, PSI e KS no
papel, sem modelo.

## Consequences

Quem clona o GitHub tem o pacote inteiro. Pastas CESAR `mlops-monitor-imagem-*`
continuam onde estão; este clone não depende delas em runtime.
