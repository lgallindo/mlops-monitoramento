# ADR 0004 — Painel no BentoML

- Status: accepted
- Date: 2026-10-06T12:24:00Z
- Deciders: Lucas Gallindo
- Relates: ADR 0003

## Context

O primeiro HTTP do painel foi `http.server`. Nas turmas CESAR o serviço
de modelo é BentoML (`bentoml serve service:…`, porta 3000, Swagger em
`/`).

## Decision

`just painel` sobe `service:Painel`. POST `/tokens`, `/regressao`,
`/imagens`. O GUI estático fica em `/gui/`; os JSONL/relatórios em
`/exemplos/`. O Swagger que o BentoML publica em `/` é o contrato vivo;
cada aba do painel embute essa página. Porta padrão do justfile: 3001
(a 3000 deste host já corre outro Bento).

## Consequences

Porta 3000 (não 8765). `gui/servidor.py` só avisa e sai.
