# ADR 0003 — Uma aba por modelo, pedido ao vivo

- Status: accepted
- Date: 2026-10-06T12:07:00Z
- Deciders: Lucas Gallindo
- Supersedes: ADR 0002

## Context

O painel em três colunas só lia JSON. Faltava escolher um modelo e mandar
um pedido novo para ver PSI/KS/p95 mudarem na hora.

## Decision

Navegação por abas (`role=tab`): Tokens, Regressão, Imagens. Cada aba tem
formulário e tabela. POST `/api/tokens`, `/api/regressao`, `/api/imagens`
acrescenta linha em `recente.jsonl`, chama o `monitor.py` da pasta, devolve
o relatório. A aba ativa redesenha a tabela com a resposta.

## Consequences

O HTTP deixa de ser só arquivos estáticos. Sem baseline (`just gerar`) o
POST de regressão falha. O poll de 5 s continua nas três pastas.
